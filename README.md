# ✍️ Signature Pad Plugin for Bubble

This is a custom **Signature Pad Plugin** designed specifically for the [Bubble.io](https://bubble.io) no-code platform. It allows users to draw and capture signatures directly within their Bubble applications.

---

## 🚀 Features

- Draw smooth, vector-based signatures
- Clear and reset functionality
- Export as image (Base64 PNG)
- Fully customizable width and height
- Responsive design

---

## 🛠️ Technologies Used

- **JavaScript** — for drawing logic and canvas control  
- **CSS** — for styling and responsive layout
